PlantDex is built entirely on open tools, public domain science, and permissive community datasets.

Google AIY Plants Classifier V1

Apache 2.0 License

Quantized TensorFlow Lite vision classifier trained on over 2,100 botanical taxa. Developed by the Google AIY Projects team for energy-efficient on-device edge computing.

Wikipedia & Wikimedia Commons

Global Biodiversity Information Facility (GBIF)

CC0 / Open Data

Taxonomic hierarchies (Kingdom, Family, Genus) and standardized botanical nomenclature verified through the open GBIF Species Backbone API.

Core Software Stack

  • Python & Flask: Lightweight WSGI application framework (BSD-3-Clause)
  • SQLite: Embedded ACID SQL database engine (Public Domain)
  • Gunicorn: Production WSGI HTTP server (MIT License)
  • Pillow (PIL): Image processing, EXIF stripping & Lanczos downsampling (HPND License)
  • NumPy: Multi-crop array math and tensor manipulation (BSD License)
